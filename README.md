# Gravebreath

**A first-person 3D horror game that runs in the browser and on Android, from one React Native codebase.**

You wake up buried alive. Claw out of the coffin, then climb through the crypt, the catacombs and the Necropolis to the graveyard above, while something below listens for every breath you take. Five layers, three endings.

**▶ Play it now:** [gravebreath.vercel.app](https://gravebreath.vercel.app) (desktop: keyboard and mouse; phone: touch)

## What's interesting technically

- **three.js inside Expo.** The renderer draws to `expo-gl` on native and WebGL on the web, so iOS, Android and the browser share one game loop and one scene graph (`src/game/engine/renderer.ts`).
- **Simulation kept apart from rendering.** Game rules (layout generation, the Listener's hearing, the Hushmen, endings) live in `src/game/sim/` as plain TypeScript with a seeded RNG, so the same run can be replayed exactly. That logic has its own tests (`npm test`, Node's built-in test runner), and none of it needs a GPU.
- **Hand-built skinned meshes.** The hands, the Listener, the Hushmen and Cole are sculpted, rigged and animated in code (`src/game/world/*Rig.ts`, `tools/make_*.py`), not bought from an asset store.
- **Built to run on phones.** It has low, medium and high graphics settings, and a dev benchmark that walks each level and logs real frame times on a phone. That benchmark drove the work that made the catacombs fast enough for mobile, along with loading assets in the background during the story intro.
- **Sound that's part of the game.** Breathing, foley and a voiced antagonist react to what you do. Sound effects are generated by script (`tools/make_sfx.py`).
- **Ships to every platform.** EAS builds for Android (APK and Play bundle), static web export on Vercel with Web Analytics.

## Stack

React Native 0.88 · Expo SDK 58 (Expo Router, expo-gl, expo-audio) · three.js · Zustand · TypeScript · Python asset tooling

## Run it locally

```bash
npm install
npx expo start          # press w for web, a for Android
npm test                # simulation tests
npm run typecheck
```

## Layout

```
src/app/          screens (Expo Router): title, play, settings, ledger, calibrate, credits
src/game/sim/     pure game rules and tests
src/game/world/   level builders and character rigs
src/game/engine/  renderer, asset manifest, media loading
tools/            Python scripts that generate models, sounds, icons, fog and decals
```
